# Cafe Varsha Gokarna

Premium responsive restaurant website built with Next.js, TypeScript, Tailwind CSS and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Production build

```bash
npm run build
npm start
```

## Included

- Responsive single-page café website
- Cinematic hero section
- About / verified business facts
- Menu section that intentionally avoids invented dishes/prices
- Gallery using the supplied Cafe Varsha images
- Guest review section using supplied review text
- Location / directions
- Call + WhatsApp CTAs
- Mobile sticky contact bar
- Framer Motion reveal animations
- Tailwind CSS
- SEO metadata
- Accessible semantic structure

## Important content note

The project only uses the business details supplied in the brief. It does not invent menu items, menu prices, awards, certifications, or a full weekly opening schedule.
